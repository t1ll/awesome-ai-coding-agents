# AGENTS.md — Awesome AI Coding Agents

## Purpose

This repository is a curated registry of AI coding agents, coding assistants, and agentic development tools. It is intended for both human developers and automated agents looking for canonical resources.

## Scope

Cover resources that help developers write, review, refactor, and maintain code with AI assistance:

- AI coding agents and autonomous coding tools.
- IDE extensions and plugins for agentic coding.
- Code-review agents and pair-programming assistants.
- Reference implementations and workflows for agentic software engineering.

## Style

- Follow the same format as the other `awesome-*` repositories in the Enterprise AI Atlas organization.
- Label official/vendor resources as `Official` and third-party resources as `Community`.
- Prefer official documentation and GitHub repository links.

## Maintenance

- Run `./scripts/validate-links.sh` before finishing any edit.
- Place entries under the topic or agent type they primarily target.

## Important reminders

- Do not provide legal advice.
- Verify that links resolve and are current.
